出于安全原因，MC默认禁用软链接[^1]，这对数据包开发不太友好。<br>

## 启用方式

首先，在客户端`.minecraft`或者服务器根目录下面创建一个`/allowed_symlinks.txt`文件，并在其中输入软链接指向的文件/目录：

```text  

# 以#开头的行是注释
# 可以使用正则表达式，这个可以允许所有软链接
/.*/g
# 或者参考 .gitignore 的格式
/foo/bar/*
# 也可以直接使用完整路径
/foo/bar/file
```

每次修改都需要重新启动客户端/服务器。

## 注释与参考

[^1]: [Enable Symbolic Links in Minecraft: Java Edition. MinecraftHelp. help.minecraft.net](https://help.minecraft.net/hc/en-us/articles/16165590199181)
