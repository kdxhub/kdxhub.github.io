直接说结论：一般是`ssh-agent`的套接字没有清理等原因，导致其无法启动，阻塞SSH服务工作。

解决方案：

```bash
# 结束已有进程
sudo killall ssh-agent
# 移除套接字
sudo rm -rf ~/.ssh/agent/
# 再次使用SSH服务
ssh -T git@github.com
```
